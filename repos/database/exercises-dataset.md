## 一句话
健身动作的结构化数据集——收录 **1324 个动作**,含动画 GIF、缩略图、肌肉群/器械数据和 6 种语言的分步说明,是 LogPress 应用的数据层。

## 内容与亮点
- **核心能力**：1324 个健身动作,带 `animation GIF`、`180×180` 缩略图、肌肉群与器械数据、6 语言分步说明
- **数据格式**：**JSON** 结构化,可直接用于健身 App 开发
- **生态关联**：是 LogPress 健身应用的数据层
- **适用**：让 AI 基于它做健身小程序/App,省去自己造动作数据

## 如何使用
```bash
# clone 后直接使用 JSON 数据
git clone https://github.com/hasaneyldrm/exercises-dataset
# 或下载数据文件
```
- 提示词示例：「请你基于这个开源项目做一个健身的小程序给我，我自己用不需要数据库。所有 GIF 资源下载到本地，如果有包大小限制，可以采用分包策略。」

## 对我的价值
做健身 / 健康类 App 时直接可用的数据源——不用自己整理动作库。适合 AI 辅助快速搭建健身产品的数据层。值得实践。
