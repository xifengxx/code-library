## 一句话
**Android TV / 电视盒子应用合集**：把全网影视、直播、K歌、游戏、教育、工具类 APK 整理成一张 README 总表（版本号 + 直链 + 可用状态 + 备注），同时汇总 **TVBox 接口源**与 **IPTV 直播源**，配套网站 app.iyouhun.com。仓库仍在高频更新（2026-10 仍在提交）。

## 内容与亮点
- **README 即数据库**：近百个 App 一览表，每行含**版本号、APK 直链、🟢/🔴 状态灯、适配与使用备注**（如「兼容安卓 4.4」「需配置接口源」「已停止转播」）
- **七大分类目录**：影视（`影视/`）、电视直播（`电视直播/`）、K歌（`K歌/`）、娱乐应用、教育学习、运动健身、实用工具
- **两类资源分开放**：**应用 APK** 直接托管在仓库里（无 Releases、无 CI，靠人工维护），**接口源 / 直播源**以纯文本清单给出
- **空壳 vs 内置源**：区分得很清楚——TVBox / 影视仓 / FongMi影视 / OK影视 等是**空壳**，装完必须填接口源；月光宝盒、小苹果、欧歌等是**内置源**，安装即用
- **接口源层级**：README 专门解释了**单线路 / 多线路 / 多仓**的概念，并给出一批单仓、多仓 JSON 地址
- **直播源矩阵**：按 **纯 IPv4 / 纯 IPv6 / 混合 / 海外** 分组，含 M3U、TXT、EPG 节目单
- **维护活跃**：pushed_at 显示仍在持续更新；部分应用明确标注失效（🔴），说明有人在跟进可用性

## 如何使用
**在线浏览**：https://app.iyouhun.com （分类索引、兼容性标注）

**装到电视 / 盒子**：
1. 电视或盒子开启「允许安装未知来源应用」
2. 在 README 一览表里点对应 APK 下载（或在电视浏览器里直接打开仓库页面）
3. 用 U 盘拷贝安装，或先用**野草助手 / 欢视助手**把 APK 推送到电视再安装

**空壳类配置**（TVBox / 影视仓 / FongMi / OK影视）：
- 打开软件 → 设置 → 配置地址，粘贴 README「接口源」里的**单仓或多仓 JSON**
- 直播源则填入 `M3U/TXT` 地址（纯 IPv6 源需要宽带支持 IPv6）

**本地克隆**（仓库内有大量 APK，体积不小）：
```bash
git clone https://github.com/youhunwl/TVAPP
```
注意：README 提示部分 GitHub 托管的源地址在国内需要自行加代理。

## 对我的价值
**作为工具直接可用，作为代码没有学习价值**——仓库里没有应用源码，本质是一个精选资源目录 + APK 存储。

真正值得看的是它的**索引型仓库运营方式**：不建站、不做数据库，用一张 README 表格承载「版本 / 直链 / 状态 / 备注」四类信息，配合分类目录和状态灯，2.5 万 star 全靠人工维护的可用性口碑。如果我要做一个「资源导航」类项目，这种**低技术成本、高信息密度**的结构比写爬虫更务实。它与本库的 `free-programming-books` 属于同一类：**内容组织本身就是产品**。

**必须说清的风险**（比技术价值重要）：
- **版权与合规**：影视、直播源绝大多数是未授权转播，README 自己也写「严禁商用，如有侵权请联系删除」；在国内属于明确的灰色地带
- **APK 不可信**：大量安装包是第三方修改版，标注「解锁 VIP / 去广告 / 免登录」，来源无法验证，存在植入与隐私风险；只适合隔离的旧电视盒子，**不要装在存有账号或工作资料的设备上**
- **稳定性**：接口源和直播源寿命通常只有几周到几个月，失效是常态，需要持续换源

个人家庭影音折腾可参考；**任何工作、投研、私募相关设备都不建议安装**。
