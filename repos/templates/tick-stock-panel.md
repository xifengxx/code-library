## 一句话
TSP 是一个 **A 股智能量化工作台**：自托管、单 Docker 容器、零外部数据库，数据 100% 落在本地 Parquet。覆盖策略、回测、监控、因子挖掘、AI 助手，并把全部核心能力开放成 **61 个 API 端点 + 12 个 MCP 工具**。它的价值不在「A 股工具」（领域窄），而在**一套自洽、被 2400+ 测试守护的量化系统架构样本**。

## 内容与亮点
- **存 15 列、现算 68 列**：只落盘 15 列基础数据，68 列指标与信号在读取时现算（进程内快照缓存）——存储最小化、读取零冗余、写入即失效，避免「指标口径一改就得全量重算」
- **回测 = 实盘同路径**：全项目**只有一条** `StrategyEngine.run` 执行路径；分钟策略逐交易日回放 + 「当日已知」纪律，**架构级杜绝未来函数**；自研仓位模拟引擎支持 T+1 / 手续费 / 滑点 / 止损
- **财务多源按 PIT 合并**：按 `(symbol, period_end)` 报告期累积，多源取并集、逐列按**公告日**取最新，**公告前一律空值、绝不填 0**——这是最隐蔽的未来函数来源，作者显式处理
- **能力路由矩阵**：6 类数据集按数据源声明的能力独立路由，换源不换口径（指标与回测结果不变）；**fail-closed**——未声明 `pct_unit` 即拒绝，不猜默认值
- **重活进程隔离**：回测跑在 spawn worker 子进程，持久 run ID，刷新/切页重连不丢任务，主服务永不被计算卡住
- **核心域 / 扩展域边界**：8 个核心域拥有数据与语义，5 条扩展通道（数据源插件 / 扩展数据表读写 / 自定义策略信号 / 声明式页面插槽 / 后端 custom 模块）只消费契约，**删除目录即整体卸载，零核心改动**；**AI 对话助手自己就是该机制的参考实现**
- **开放网关**：面板密码会话与 Token 通道**并行互不影响**；Token SHA-256 哈希存储、明文只显示一次、吊销立即生效；**六档 scope**（read:market / read:ext / write:ext / read:analysis / run:backtest / paper:trade），管理面永不开放；网络门禁默认仅本机/内网（门禁先于验签，不泄露 Token 有效性也不消耗限流额度）
- **契约稳定性靠测试守护**：61 端点有机器可读契约（`GET /api/openapi.json?tier=a`）+ **契约快照测试**，开放面变更必须显式改快照，CI 拦截无意识变更
- **交易日探针**：fuyao 交易日历（含调休）→ 行情时间戳探针 → 工作日兜底，节假日自动停掉实时轮询与分钟增量，零无效请求
- **AI 助手（可选）**：21 个查询工具 + 4 个动作工具（生成信号 / 回测 / 加自选 / 数据补全），**写操作先弹确认卡**（完整待执行参数可见，确认/取消/120s 超时自动取消）才执行；逐字流式 + 工具调用足迹卡（参数与耗时可展开核对）
- **明确不做**：不对标同花顺/通达信，**不内置 AI 荐股 / 涨停预测**
- **适用**：A 股策略研究、因子挖掘与回测、盘中监控；以及作为全栈量化系统的架构参照

## 如何使用
**最快路径——一条命令**（已装 Docker）：
```bash
docker run -d --name tsp -p 3018:3018 -v ${PWD}/data:/app/data \
  ghcr.io/shy3130/tick-stock-panel:latest
# 打开 http://localhost:3018
```
**Compose 本地构建**（跑自己改的代码）：
```bash
cp .env.example .env
docker compose up --build
```
**Dev 模式**（二次开发，需 Python ≥ 3.11 · Node ≥ 20 · uv · pnpm）：
```bash
cp .env.example .env       # 按需填 TICKFLOW_API_KEY(留空 = None 模式)
./dev.sh                   # 后端 :3018 · 前端 :3011
```
**桌面客户端**：Releases 下载（Windows exe / macOS **仅 Apple Silicon** dmg；macOS 首次打开需去「隐私与安全性」放行，或 `xattr -dr com.apple.quarantine /Applications/TSP.app`）。
核心配置（`.env`）：
```ini
TICKFLOW_API_KEY=   # 留空 = None 模式(历史日K免费);填 Key = 按订阅档位解锁
AI_API_KEY=         # 留空 = 关闭 AI;填 Key 启用策略生成与 AI 对话助手
PORT=3018
```
**开放接口调用示例**：
```bash
curl -H "Authorization: Bearer tsp_xxxx" \
  "http://localhost:3018/api/kline/daily?symbol=600519.SH&limit=10"
```
依赖：Docker（推荐路径）；Dev 模式需 Python 3.11+ / Node 20+ / uv / pnpm。数据源为 TickFlow（内置默认）与 fuyao（同花顺 REST，需自备 Key），均需遵守其服务条款。

## 对我的价值
**领域窄但可迁移性极高——这是我在中文开源里少见的、想清楚了的量化系统架构样本。** 它纯 A 股，没有任何加密货币 / 链上数据 / RWA 能力，但下面六条答案是**任何量化系统都会遇到**的问题，做链上数据研究同样可以一条不改地照搬：

| 一定会遇到的问题 | TSP 的答案 | 迁移性 |
|---|---|---|
| 指标口径改了要不要全量重算 | 存 15 现算 68 | 任何列式数据集 |
| 换数据源要不要重写拉数层 | 能力路由矩阵 + fail-closed | 任何多源系统 |
| 回测和实盘两块代码对不上 | 只此一条 `run` 路径 | 任何策略系统 |
| 财报数据带来的未来函数 | PIT 按公告日、公告前空值 | 任何基本面回测 |
| 长任务把主服务卡死 | spawn worker + 持久 run ID | 任何服务 |
| 扩展功能越加越烂 | 核心域/扩展域 + 删目录即卸载 | 任何插件化系统 |

**建议用法：不装，读文档。** 四份方法论沉淀比代码值钱——`docs/open-platform-plan.md`（扩展边界与 Token 体系）、`docs/mining.md`（因子挖掘的防泄漏口径）、`docs/market-phase.md`（情绪周期口径设计）、`docs/strategy-iteration.md`（AI 策略迭代协议：台账 / 证据包 / 门槛判定）。

**需要知道的利益结构**（影响可持续性判断，非缺陷）：
- 默认数据源 TickFlow 的链接带**推广返佣参数**（`?ref=...`），首页 RunningHub 赞助 banner 带**邀请码**，另有微信赞赏码并写明「**优先响应赞助回馈**」——这是**个人项目 + 返佣变现**形态，不是公司维护，「优先响应赞助」对需要长期稳定支持的团队是真实风险
- **「自托管免费」指软件免费，数据另算**：TickFlow 分 None/Free/Starter/Pro/Expert 档，留空仅历史日 K 免费，实时行情 / 全量分钟 / 财务等按档位解锁
- **数据合规责任被明确推给部署者**：README 原文「行情数据对第三方再分发需符合数据源服务条款与交易所授权要求，**合规责任由部署者承担**」——个人研究无碍，作为私募正式生产环境需谨慎评估数据授权链路
- 交流群里「作者个人维护了一些个性化接口统一公布在群公告」——非公开契约的扩展能力，存在锁定与不可预期风险
