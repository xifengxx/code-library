## 一句话
现代开源健身训练平台——可创建训练计划、记录进度,带动作说明和视频演示的健身 Web 应用。

## 内容与亮点
- **核心能力**：创建训练计划、跟踪进度、访问完整动作数据库,含动作说明与视频演示
- **技术栈**：**Next.js** + **React** + **TypeScript** + **Prisma** + **PostgreSQL** + **TailwindCSS** + **shadcn-ui** + **Radix UI**
- **架构**：采用 **Feature-Sliced Design**（功能切片）分层,前端 SPA 风格 + 服务端渲染混合
- **多语言**：支持多语言
- **规模**：8000+ Star,活跃维护（2026-07 还在更新）

## 如何使用
```bash
git clone https://github.com/Snouzy/workout-cool
cd workout-cool
# 按 README 配置数据库(PostgreSQL)并启动
npm install && npm run dev
```
