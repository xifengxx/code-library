## 一句话
「一句话把开发的网站发布到线上」——把本地静态网页、图片或任意文件,快速变成一个谁都能访问的公网链接的部署工具。

## 内容与亮点
- **核心能力**：单命令前端部署（Deploy Your Frontend in a Single Command）,支持 **Claude Code Skill**
- **零配置**：无需服务器配置,本地文件直接上线
- **部署方式**：全栈前后端分离架构,后端跑在 **Edge Runtime**,数据库用 **Serverless SQL**,静态资源走 **IPFS** 分布式存储
- **规模验证**：项目累计已帮用户部署超过 100 万个网站
- **平台能力**：内置邮件推送和 LLM 调用能力,Worker 中可直接调用

## 如何使用
```bash
# 安装 Claude Code Skill
npx skills add glitternetwork/pinme
```
- 之后用一句话让 Claude 把当前项目/文件部署上线
- 在线体验：https://pinme.dev/

## 对我的价值
快速把 prototype / 静态页 / 小工具部署上线的最佳参照——尤其是「Serverless + IPFS 静态托管」这种低成本方案。开发新项目想快速给别人看效果时,值得实践。
