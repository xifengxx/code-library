## 一句话
构建 LLM 应用（**Agent** / **RAG** / 链式编排）最流行的 Python 框架，把模型调用、提示词、工具、记忆、检索统一成可组合的组件。

## 内容与亮点
- **核心能力**：`LCEL` 声明式链式应用、Agent/工具调用、RAG 组件链、`LangGraph` 有状态多智能体编排
- **生态**：内置大量第三方集成（各家模型供应商、向量库、工具），教程多、社区大，问题易搜到答案
- **适用**：从快速原型到生产级应用（配合 LangSmith 做可观测）

## 如何使用
```bash
pip install langchain langchain-openai
```
- 常用搭配：`langchain-core`（核心）、`langchain-community`（集成）、`langgraph`（编排）
- 快速上手：https://python.langchain.com/docs/tutorials/

## 对我的价值
做 LLM 应用时的主要参照；tour-app 同类的 DeepSeek 集成场景可对比「框架 vs 手写」的取舍；学习 RAG / Agent 的标准架构。
