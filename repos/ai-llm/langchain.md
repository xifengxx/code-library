## 一句话
构建 LLM 应用（Agent / RAG / 链式编排）最流行的 Python 框架。

## 作用与亮点
- 把模型调用、提示词、工具调用、记忆、检索统一成**可组合的组件**
- 内置大量第三方集成：各家模型供应商、向量数据库、工具库
- 生态最全、教程最多、社区最大，遇到问题基本都能搜到现成答案
- 既适合快速原型，也支撑生产级应用（配合 LangSmith 可观测）

## 主要内容
- **LCEL**：声明式组合链式应用（`|` 管道语法）
- **Agent / 工具调用**框架：ReAct、函数调用、多智能体
- **RAG** 组件链：文档加载、切分、向量检索、重排
- **LangGraph**（独立库）：有状态、可持久化的多智能体编排

## 对我的价值
做 LLM 应用时的主要参照；用 tour-app 同类的 DeepSeek 集成场景时，可对比"框架 vs 手写"的取舍；学习 RAG / Agent 的标准架构。
