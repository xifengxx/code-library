## 一句话
面向**中国大陆居民**的海外资本利得税计算工具——把海外券商文件整理成个人申报参考底稿,「可以不报,不能不知道」。

## 内容与亮点
- **核心能力**：导入券商材料,整理出个人申报所需的应纳税所得额
- **识别与整理**：自动识别券商和文件类型,核对逐笔交易、补充历史成本、订正解析结果
- **计算方法**：对比**自然年 FIFO** 与 **ACB** 两种成本法
- **覆盖范围**：计算财产转让所得与利息、股息、红利所得
- **输出**：生成可复制数字和可保存 PDF 的申报参考底稿
- **背景**：海外券商交易/分红/转仓材料分散在不同报表,个人申报需手动整理成本、汇率、应纳税所得额和海外已纳税额,TaxCheck 自动化这个过程

## 如何使用
- 在线使用：https://tomczhang.github.io/tax-check/
- 或按 README 本地运行

对海外投资（美股/港股）的财务工具直接有用——报税季整理底稿的好帮手。也可作为「金融合规工具」类项目的参照。值得实践并记录。
