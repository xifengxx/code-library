## 一句话
开源桌面录屏 + 编辑工具——录完之后自动帮你把画面处理好看,无需剪辑技能即可产出精致 demo 视频。

## 内容与亮点
- **核心能力**：录屏后自动美化,**光标变平滑、运动模糊、点击时自动放大关键区域、套上好看的边框和背景**
- **光标美化**：平滑移动、运动模糊、点击弹跳、摇摆效果,甚至可用 macOS 风格光标素材
- **摄像头气泡**：把摄像头画面叠在录屏上,支持位置、大小、圆角、阴影自定义
- **时间线编辑**：拖拽式编辑器,支持裁剪、变速、添加标注、额外音轨
- **样式化输出**：内置壁纸、渐变背景、圆角、阴影、画面比例预设
- **扩展市场**：社区驱动的插件系统,可安装点击音效、设备边框、浏览器 mockup 等
- **导出**：支持 MP4 和 GIF,质量可选;**跨平台**（macOS / Windows / Linux）
