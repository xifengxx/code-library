## 一句话
「AI 代理时代的 HTML 编辑器」——你的本地 AI Agent 写 HTML,你负责发布。核心理念是「Markdown 是草稿,HTML 才是给人看的最终产物」。

## 内容与亮点
- **核心能力**：本地运行的 HTML 生成器,对接 8 个主流 AI 编程 CLI（**Claude Code** / Cursor / Codex / Gemini / Copilot / OpenCode / Qwen / Aider）
- **75 个 Skill 模板**：覆盖杂志、演示文稿、海报、小红书 / 推文、原型、数据报告、Hyperframes 等 9 种内容表面
- **沙箱预览**：生成结果在受控环境预览,避免恶意代码
- **一键导出**：直接发到微信 / X / 知乎,或下载 `.html` / `.png`
- **零 API Key**：复用你已登录的 AI CLI 会话,不额外收费

## 如何使用
```bash
git clone https://github.com/nexu-io/html-anything
cd html-anything
# 按 README 安装依赖并启动本地服务
```
- 打开浏览器后自动检测已登录的 AI CLI（Claude Code / Cursor / Codex 等）,在 Web 界面左侧粘贴内容（Markdown / CSV / Excel / JSON / 纯文本）,右侧实时预览生成的 HTML,按 ⌘+Enter 生成

## 对我的价值
vibe coding 场景的强力补充——用 AI 生成内容时,输出不是 Markdown 而是可直接发布的 HTML。适合做小红书/公众号图文、原型、数据报告;可作为「AI 生成内容 → 网页发布」管线的参照。
